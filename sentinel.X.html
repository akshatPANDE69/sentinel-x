The problem

Modern cheats leave modern traces.

Binary and memory patches rewrite client state before it ever reaches the server. Forged client-server handshakes hide buffer overflows behind “valid” checkpoints. Blunt anti-cheat over-corrects—honest players get trapped in account-linking deadlocks.

01

Client state is not truth

Position, health, inventory and state live on the server. The client proposes; the server disposes.

02

One signal is never enough

Kernel, memory and behavioral anomalies become correlated evidence instead of isolated accusations.

03

Trust should move with reality

A dynamic score rises and falls with real signal: deterministic logic first, ML assistance second.

The solution

A trust engine, not a ban hammer.

Sentinel-X is a continuously-running trust layer for game clients. It verifies kernel, memory and behavioral signal; it decides using deterministic engine logic; and when trust drops, the evidence chain—not a black box—shows exactly why.

◇ Source-level architecture
The architecture

Evidence that cannot quietly disappear.

Every anomaly becomes a signed, hash-linked Evidence record. Altering history is mathematically visible, not merely logged.

A

Capture

Collect high-signal observations across the kernel, memory, client and player behavior.

B

Link

Sign and hash-link every record so the timeline remains tamper-evident from source to decision.

C

Decide

Trust scores come from real engine logic. ML assists the investigation, but never gets the final vote.

◇ Source-level architecture
Continuous security

Capture → Link → Decide, running continuously.

Every cycle re-checks trust—nothing is a one-time verdict.

Cryptographic security

Hash-linked, signed, tamper-evident.

Every Evidence record is signed and hash-linked to the one before it, so the timeline itself proves whether it has been altered—rather than relying on a log that could be edited.

01

Signing

Each Evidence record is signed at capture time.

02

Hash-linking

Each record references the hash of the record before it.

03

Tamper evidence

Editing history breaks the chain instead of hiding the edit.
