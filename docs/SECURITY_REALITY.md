# 🔍 Security Reality & Honest Limitations

## What is Guaranteed
- **Strict Server Authority:** Client cannot forge positions, speeds, or hit registration.
- **Binary Attestation:** Games must match expected executable SHA-256 hashes.
- **Microsecond Recovery:** Compromised sessions are rewound and re-attested in $< 2$ ms.

## What is NOT Guaranteed
- **Physical DMA Hardware Leech Cards:** Requires IOMMU hardware virtualization controls.
- **Optical AI Screen-Capture Aimbots:** Requires statistical jerk analysis over long time windows.
